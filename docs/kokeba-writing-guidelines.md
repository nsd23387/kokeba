# Kokeba Children's Book — Template & Writing Guidelines (house style)
> The official Kokeba style. The Author agent MUST follow this. Injected alongside the
> Country Prompt + Age Prompt + Framework + Intake (see agents/author/compose-story-prompt.md).
>
> **COUNTRY-AGNOSTIC.** This style applies to EVERY market. Anything language/script/culture-specific
> comes from the **active Country Pack** — never hard-code a language here. Ethiopia/Amharic below is
> only an *example*.

## Pack-driven variables (resolved from the active Country Pack)
- `LEAD_LANGUAGE`  — the language the story/rhyme is written in (e.g. English).
- `VOCAB_LANGUAGE` — the heritage language taught on the right page (e.g. Amharic; Swahili; Yoruba…).
- `SCRIPT`         — that language's script (e.g. Ge'ez/fidel; Latin; Arabic…).
- `REPRESENTATION` — authentic, diverse representation for that culture.

## Target audience (priority order)
1. Parent read-aloud experience comes FIRST.
2. Child interaction comes second.
3. Vocabulary learning comes third.

## Story structure
1. Introduction (wake up / start the adventure)
2. Journey to the destination
3. 5–8 themed discovery spreads
4. Simple emotional reflection
5. Return home / conclusion
6. Memorable final line

## Page layout (per spread)
- **Left page:** the story in `LEAD_LANGUAGE` ONLY.
- **Right page:** full-page illustration + ONE `VOCAB_LANGUAGE` word (in `SCRIPT`) + its transliteration.
- **Do NOT force `VOCAB_LANGUAGE` into the rhyme.** It is a visual vocabulary lesson, not part of the verse.

## Rhyming
- Simple AABB couplets when possible (in `LEAD_LANGUAGE`).
- Prioritize NATURAL language over perfect rhyme; avoid forced rhymes.
- Read every spread aloud to test flow. Favor rhythm + repetition over complex vocabulary.

## Interaction (every themed spread includes ONE)
- an animal sound, a movement, a gesture, or a simple question.
- Examples: "Can you roar?" · "Can you wave?" · "Can you splash?" · "Can you stretch tall?"

## Vocabulary layout (right page)
- Large illustration + the `VOCAB_LANGUAGE` word (in `SCRIPT`) + transliteration (+ optional pronunciation).
- **Example (Ethiopia Country Pack):**  አንበሳ · Anbessa  (lion)
- (Kenya Country Pack would instead show, e.g.:  simba  — Swahili, Latin script.)

## Illustration guidance
- Bright, warm, expressive. Focus on the child + one key animal/object. Clear emotions.
- `REPRESENTATION`: diverse, authentic to the active Country Pack. Consistent character design throughout.

## Brand principles (universal)
Wonder · Curiosity · Family connection · Cultural pride · Learning through storytelling · ONE new concept per spread.

## The success test — a Kokeba story is:
- Fun on the first read · Easy on the tenth · Memorable on the hundredth.
- Short enough to finish before a toddler loses interest.
- Rich enough that the child learns something new each time.

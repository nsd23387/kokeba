# Author Agent — story prompt composition (modular)
The Author agent's prompt is ASSEMBLED from FIVE swappable parts. None is hard-coded.

```
[ Country Prompt ]   packs/country-packs/<country>/prompt.md       (what to draw on, voice, hard rules)
[ Age Prompt ]       packs/age-range-packs/<band>/prompt.md        (developmental targets + craft rules)
[ Story Framework ]  packs/story-frameworks/frameworks.yaml#<id>   (the proven structure)
[ House Style ]      docs/kokeba-writing-guidelines.md             (Kokeba template, layout, rhyme, interaction, success test)
[ Filled Intake ]    the creator's answers                         (theme, cast, culture, learning focus, refrain, tone)
        =
   ->  Author writes an ORIGINAL story to the HOUSE STYLE:
       left page = story in the pack's LEAD_LANGUAGE (rhyme) only; right page = illustration + one VOCAB_LANGUAGE word + transliteration (NOT in the rhyme);
       intro -> journey -> 5-8 discovery spreads (each with an interaction prompt) -> reflection -> home -> memorable final line.
   ->  Illustration -> Layout (fidel embedded, see docs/fidel-rendering.md)
   ->  COLLECTIVE native review (Gate 1) on the laid-out proof -> Compliance pre-flight -> Export -> KDP
```

Swap any part to change the output. The framework gives STRUCTURE; the house style gives FORMAT + craft bar.
Never reuse wording/characters/art from cited bestsellers.

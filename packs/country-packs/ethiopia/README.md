# Ethiopia Country Pack
Two things in one, both modular:
- **Inventory** (data the engine reads): inventory.yaml, characters/, culture/, keywords.yaml, brand-kit/, country.yaml
- **Prompt** (LLM context): prompt.md — the compiled "country knowledge" injected into the story agent

Swap this whole folder to launch another country; the engine, frameworks, and age packs stay identical.
Gate 1 (native review) is required before any title ships.

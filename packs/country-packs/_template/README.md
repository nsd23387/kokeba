# _template Country Pack
Copy this folder to add a market. Fill country.yaml, characters/, culture/, keywords.yaml, brand-kit/.
Assign a native reviewer before publishing.

## Characters (REQUIRED, unique per country)
Run the Character Designer (agents/character-designer) to create THIS market's own original character(s)
into characters/. Never reuse another country's cast. The character's name should be meaningful in the
pack's vocab_language.

# 0-3 Age-Range Pack
Modular, two parts:
- **spec.yaml** — format/industry spec (board book, word/page counts, CPSIA flags)
- **development.yaml** — the developmental inventory (milestones, learning goals, what works at 0-3)
- **prompt.md** — the compiled developmental prompt injected into the story agent

Swap this folder to target a different age band (3-6, 6-9); the engine + Country Pack stay the same.
